# ML P2 Fixes Implementation Plan — Prior-Lead Alignment (#7) + Champion Fresh Re-evaluation (#6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Close the two deferred ML limitations that directly affect production trustworthiness: (**#7**) align the market-prior lead time across training / evaluation / serving to `T-48h`, and (**#6**) gate champion vs challenger on a *fresh, same-window* evaluation of the champion instead of its stored metrics.

**Architecture:** #7 adds a per-match cutoff (`kickoff − ML_PRIOR_LEAD_HOURS`) to the existing window-function snapshot picker in `app/ml/dataset.py`, using a dialect-aware expression (SQLite `datetime(col,'-N hours')`, PostgreSQL `col - make_interval(hours => N)`); CLV keeps the true closing line (lead 0). #6 adds an optional `champion_metrics` override to `registry.maybe_promote`, computes the champion's fresh metrics off-loop in `jobs._train_challenger_sync` by loading its artifact and evaluating on the same `dataset.eval` window + same closing priors, and wires it through `retrain`.

**Tech Stack:** unchanged (Python 3.11+, async SQLAlchemy 2.x, LightGBM, pytest, ruff).

## Global Constraints

- Scope is exactly **#6 + #7**. Do NOT touch #4 (market Brier baseline) or #5 (CLV over all outcomes) — they stay in the spec's known-limitations list.
- **CLV must always be measured against the true closing line** (lead 0); only *feature/eval* priors use the lead. Mixing them would silently redefine CLV.
- New setting: `ml_prior_lead_hours: int = 48` (0 = legacy "latest snapshot strictly before kickoff").
- `lead_hours <= 0` must preserve today's exact behaviour (`captured_at < kickoff`) — that is the legacy path and what the CLV call site uses.
- Cutoff comparison is strict `<` (matches the existing style); do not write tests that depend on sub-second boundary equality (SQLite stores microseconds, the SQLite cutoff expression truncates to seconds).
- Timestamps stay aware-UTC; no amount/units changes.
- Gates: `uv run pytest` (live deselected) + `uv run ruff check .`; Chinese `type: 描述` commits; branch `ml-p2`; never commit to `main`.

```python
def _prior_cutoff(lead_hours: int):
    """SQL for `Match.kickoff_time - lead_hours`, dialect-aware (SQLite vs PostgreSQL)."""
    if lead_hours <= 0:
        return None  # legacy path: strictly before kickoff, no arithmetic
    if _current_dialect() == "sqlite":
        return func.datetime(Match.kickoff_time, f"-{lead_hours} hours")
    return Match.kickoff_time - func.make_interval(0, 0, 0, 0, lead_hours)
```

```python
async def _latest_hkjc_snapshots(
    session: AsyncSession, rows: list[MatchRow], odds_type: str, lead_hours: int = 0
) -> dict[int, OddsSnapshot]:
    if not rows:
        return {}
    cutoff = None
    if lead_hours > 0:
        if session.get_bind().dialect.name == "sqlite":
            cutoff = func.datetime(Match.kickoff_time, f"-{lead_hours} hours")
        else:
            cutoff = Match.kickoff_time - func.make_interval(0, 0, 0, 0, lead_hours)
    ranked = (
        select(
            OddsSnapshot.id.label("snapshot_id"),
            func.row_number()
            .over(
                partition_by=OddsSnapshot.match_id,
                order_by=OddsSnapshot.captured_at.desc(),
            )
            .label("rn"),
        )
        .join(Match, Match.id == OddsSnapshot.match_id)
        .where(OddsSnapshot.match_id.in_([row.match_id for row in rows]))
        .where(OddsSnapshot.odds_type == odds_type)
        .where(OddsSnapshot.source == "hkjc")
        .where(OddsSnapshot.inplay.is_(False))
        .where(
            OddsSnapshot.captured_at < cutoff
            if cutoff is not None
            else OddsSnapshot.captured_at < Match.kickoff_time
        )
        .subquery()
    )
    stmt = (
        select(OddsSnapshot)
        .join(ranked, ranked.c.snapshot_id == OddsSnapshot.id)
        .where(ranked.c.rn == 1)
    )
    return {snapshot.match_id: snapshot for snapshot in (await session.execute(stmt)).scalars()}
```
   (Keep `func`/`select`/`Match` imports; no new imports needed.)

```python
async def maybe_promote(
    session: AsyncSession,
    challenger: ModelVersion,
    margin: float,
    champion_metrics: dict | None = None,
) -> bool:
    """Promote the challenger when it beats the champion's benchmark.

    ``champion_metrics`` overrides the champion's STORED metrics with a fresh
    evaluation on the current holdout (fix #6) so the gate never compares two
    different time windows; ``None`` keeps the legacy stored-metrics behaviour.
    """
    champion = await get_champion(session, challenger.target)
    if champion is None:
        await promote(session, challenger)
        return True
    baseline = champion.metrics if champion_metrics is None else champion_metrics
    if gate_passes(challenger.metrics, baseline, margin):
        await promote(session, challenger)
        return True
    return False
```

```python
def _fresh_champion_metrics(
    target: str, path: str | None, eval_df: pd.DataFrame, closing_priors: dict
) -> dict | None:
    """Re-evaluate a stored champion on the CURRENT eval window (fix #6).

    Returns None when the champion cannot be evaluated (missing/corrupt artifact,
    empty label subset) — the caller then falls back to the stored metrics.
    """
    if path is None:
        return None
    subset = "label_1x2" if target == TARGET_1X2 else "label_handicap"
    frame = eval_df.dropna(subset=[subset])
    if frame.empty:
        return None
    try:
        model = load_artifact(path)
        features = frame[FEATURE_COLUMNS].to_dict("records")
        if target == TARGET_1X2:
            metrics = evaluate_1x2(predict_proba(model, features), frame["label_1x2"].tolist())
            metrics.update(clv_metrics(_model_probs_1x2(model, frame), closing_priors))
            return metrics
        return evaluate_handicap(predict_proba(model, features), frame["label_handicap"].tolist())
    except Exception as exc:  # a broken champion must not block retraining
        logger.warning("could not re-evaluate champion for %s: %s", target, exc)
        return None
```
